# First AI workflow worksheet

Use fictional or redacted information when practising. Copy this into a note and fill it in.

- **My business does:** [one sentence]
- **The repeated task is:** [one sentence]
- **It starts when:** [trigger]
- **The input I can safely share is:** [source]
- **The output I need is:** [format and recipient]
- **A good result must include:** [facts]
- **It must not invent or disclose:** [limits]
- **I will check the result by:** [specific test]
- **I will try it on:** [two or three safe examples]
- **Only after it works, I might:** [save prompt / make skill / schedule / build app]

**Fictional example:** A small repair shop receives many questions about opening hours and pickup times. Its first AI task is to draft replies using a current, owner-approved FAQ. The owner checks each draft against the FAQ before sending. No customer message or contact details are needed for the practice run.
