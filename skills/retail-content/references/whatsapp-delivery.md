# Return results on WhatsApp

The recipient and purpose must be authorized in the request. A request to send results back to the named source chat authorizes that delivery, not public publication. Do not infer blanket permission to message every source sender.

Verify the chat header, product/price match and selected file hashes. Send one labelled product pack at a time, with its exact price qualifier and short caption. Use original-quality document delivery where supported, otherwise the highest-quality photo option. Include only a QA-passing optional reel. Never send raw chat exports, private configuration or failed variants as finished work.

When delivering for owner review, call it a review draft and list material unresolved facts. Record intent immediately before final submission. Inspect attachment count and preview, submit once, then verify outgoing messages in the correct chat. Save an exposed message ID or precise observed timestamp/attachment receipt. Distinguish sent, delivered and read.

On ambiguous completion, record `uncertain` and inspect the destination before retrying. If attachments cannot be sent, keep the local pack and report the exact limitation; provide file links/archive to the user without claiming delivery.
