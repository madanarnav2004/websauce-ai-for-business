# Website and Instagram release

Present the assets, exact copy/price qualifiers, destinations and timing. Record owner approval only from an actual decision. It applies to the reviewed content fingerprint; changes to content, files or destination invalidate the corresponding approval. A request to build the workflow does not approve unseen first-batch photos.

## Existing catalog

Use the current authenticated admin/media flow. Read the actual record first and match an existing product by confirmed ID, not a generated title. Preserve IDs, URLs, inventory and unrelated fields. For new entries use the manifest product ID consistently and check for it before retries.

Prepare a minimal patch of reviewed name, description, category, price, public media URLs and visualization labels. Unknown specifications remain absent. Preserve existing stock; new products require confirmed inventory and required category/name fields. The helper's `catalog-patch` prepares a local proposal only; it is not a publisher. Re-read the current record before applying it.

Only approved final media become public. Originals, prompts, chat evidence and review notes remain private. Do not use exposed repository credentials, widen database rules or launch an unrelated backend to bypass missing access.

Record intent before mutation. Verify saved record plus actual product page: images/order, price, availability, copy and mobile layout. Allow documented cache refresh. Save ID/live URL as receipt. Website and Instagram successes are tracked separately.

## Instagram

Verify the signed-in business account and recent posts for duplicates. Check current composer formats and crop previews. Prepare one carousel per product with hero, lifestyle and detail. Use concise factual copy, a small relevant hashtag set and a valid enquiry/showroom CTA. Do not imply caption URLs are clickable; use verified available link placement.

An optional reel needs its own reviewed cover, caption and timing. Do not schedule or flood the feed automatically. Record intent, submit once, inspect the live result and record its permalink. If uncertain, reconcile before another attempt. A successful upload is not verified publication.
