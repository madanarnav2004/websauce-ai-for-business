# Websauce case study: an inbound loop in progress

Websauce builds business websites, focused software and practical AI. The current public site is [websauce.in](https://websauce.in). The team is using its own website refresh and enquiry flow as material for educational content.

A first article about checking a website enquiry destination is live: [Test your website enquiry form before launch](https://websauce.in/journal/test-website-enquiry-form-before-launch). A related educational Instagram post was also published. The website refresh carousel and process video were prepared for later slots at the time this document was written; local queue entries were not Instagram publications.

The useful lesson is operational: the agent can draft content, inspect a path, queue work and record receipts, while the founders decide commercial terms and resolve real conflicts. The present system uses a private local ledger and Codex on a Mac. This public repository contains neither private lead data nor a running inbound service.
