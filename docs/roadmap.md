# Roadmap: useful AI for business owners

This is an education and open-source roadmap, not a list of shipped features. A new module is **ready** only when a reader can use its instructions on a safe example and see the result.

## Ready now

- First-task guide and worksheet for business owners.
- Plain-English guide to choosing a prompt, skill, schedule or app.
- Inbound engine skill, fictional brief and worked output.
- Growth operating templates for daily reviews, publication and measurement.
- Dated Websauce case study with explicit limits.

## Next useful modules

1. **Customer enquiry assistant:** turn a real enquiry into a concise internal summary and a draft reply, using synthetic data in the public demo. Never claim a draft was sent.
2. **Website launch checker:** walk through navigation, mobile layout and whether a test enquiry arrives at the right destination. It should stop when account access or bot verification is unavailable.
3. **Content from actual work:** turn one real project change into a useful post, while checking client rights and claims.
4. **Small-team operations:** turn meeting notes into decisions, owners and due dates; use only the notes the user provides.
5. **Cloud starter projects:** simple, free-tier-friendly patterns for forms, dashboards and automations, with current pricing and limits checked before publishing each guide.

These will arrive as guides, skills or runnable examples according to what the task actually needs. We will not create a separate skill for every prompt.

## Later

- Optional integrations for common tools through their supported interfaces.
- A synthetic local receipt ledger for actions that can be accidentally repeated.
- Fully runnable example apps when a guide alone is insufficient.

For each module, publish: who it helps, input needed, exact output, 10-minute example, cost or account requirements, what the agent can do, what a human must decide, and observed limitations. Open-source code and an educational video should point to the same working artifact.

We will not publish Websauce's private CRM, contact lists, personal profiles, browser state, authentication data or unverified business claims.
