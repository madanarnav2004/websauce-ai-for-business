# Product roadmap

## Version 0.1: agent-first documents

- Reusable inbound-engine skill.
- Example brief and local practice prompt.
- Daily-run template, publication protocol, measurement guide and honest Websauce case study.
- No connector, scheduler, live account or private data bundled.

## Next: a runnable demo

Add a synthetic campaign workspace and a small local receipt ledger, extracted and generalized from the private Websauce operator only after a fresh-repository audit. The demo should show prepared → submitted → confirmed or uncertain, including reconciliation before retry. It should never send or publish by default.

## Later: optional adapters

Add documented adapters for systems people already use, only where their official interfaces and permissions support it. Keep browser/session-specific behavior explicit. Add examples for content review, site QA and inbound triage, with account access provided by the user rather than baked into the repo.

**Proof of value:** a new user can use the skill on their own verified work, publish one helpful asset through their authorized account, receive a genuine enquiry through a working path and tell what happened. The repo does not promise this outcome.
