# Repository guidance

This is a public educational hub for business owners. Write for someone who understands their business but may not write code. Lead with the job, the inputs and the visible result. Mark every item **ready**, **example**, **prototype** or **planned** truthfully; do not present a schedule template as an active automation or a draft as a published result.

Keep committed examples synthetic or already public and clearly sourceable. Do not copy Websauce's private operating files, the user's home directory, browser sessions, production CRM or personal-brand context into this repo. Never commit credentials, real leads, private customer messages, provider receipts or unlicensed media.

The current reusable skill is `skills/inbound-engine/SKILL.md`. Changes to that skill must preserve its narrow scope and pass the skill validator. New skills need a specific repeatable workflow; use a guide for ordinary advice and code for deterministic repeated work.

Changes to this repo do not authorize actions on a live account or website. For a live task, verify that task's authorization, identity, factual claims and external receipt separately.
