# Repository guidance

This is a public educational repo. Keep every committed example synthetic or already public and explicitly sourceable. Do not copy files from Websauce's private operating directory, the user's home directory, a browser session, or the production CRM. Never commit access tokens, contacts, inbound messages, provider receipts or private timelines.

The reusable skill lives in `skills/inbound-engine/SKILL.md`. For work on that skill, preserve its narrow inbound scope and run the skill validator. The public docs may describe operating patterns; they must not claim a draft, local queue item, automation, or scheduled prompt has published content or generated sales.

Changes here do not authorize actions on Websauce's live site or social accounts. If a task asks for live work, verify that task's authorization, current account identity, content accuracy and publication receipt separately.
